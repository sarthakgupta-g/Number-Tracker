# Number-Tracker
Collects the numbers entered and displays how many times each number was entered

Input: 
- number of numbers
- each individual number

Output:
- each unique number and their frequencies

Ex:
- input: enter 5 numbers
- input: 1
- input: 2
- input: 1
- input: 5
- input: 2
- output: 1 appears 2 times, 2 appears 2 times, 5 appears 1 time
